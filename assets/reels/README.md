# Reels video files

Add portrait MP4 clips here using these names so the portfolio cards can play them:

- reel-01.mp4
- reel-02.mp4
- reel-03.mp4
- reel-04.mp4

Recommended export: 9:16 portrait, H.264 video in an MP4 container, 1080 × 1920. The work section shows poster thumbnails until the matching video file is added. To add more cards, duplicate a `<video>` card in the Reels section and update its video path, poster, and number.
